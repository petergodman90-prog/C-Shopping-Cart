# C Shopping Cart

A simple console-based shopping cart program written in C.

## About the Project

This project is a beginner-friendly C program that allows a user to:

- Enter the name of an item
- Enter the price of the item
- Enter the quantity they want
- Calculate the total cost
- Display the purchase summary

## Technologies Used

- C Programming
- GCC Compiler
- Linux Terminal

## How It Works

The program collects information from the user using `fgets()` and `scanf()`.

It then calculates the total using:

```text
Total = Price × Quantity```

Finally, it displays the quantity purchased, item name, and total cost.

Example
What item would you want to buy: beans
What is the price for each item: 5
How many would you like: 4
